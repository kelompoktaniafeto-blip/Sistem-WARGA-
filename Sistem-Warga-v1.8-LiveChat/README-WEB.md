# SISTEM WARGA v1.6

Aplikasi dasar Sistem Informasi WARGA berbasis Node.js + Express + MySQL/MariaDB dengan frontend responsive PWA.

## Target perangkat
- Android phone/tablet melalui Chrome/Edge dan PWA.
- PC/laptop Windows melalui Chrome/Edge atau browser modern.
- Satu frontend responsive untuk layar kecil dan desktop.

## Modul dasar
Dashboard, data warga, pengajuan surat, status dokumen, notifikasi, peta/GPS, kontrol kamera, pengaturan identitas instansi, dan backend API.

## Jalankan
`npm install` → siapkan `.env` → database → `npm start` → buka `http://localhost:3000`.

Lihat `docs/ANDROID-PC.md` untuk instalasi Android dan akses dari PC/laptop melalui LAN.
